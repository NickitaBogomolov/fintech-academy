# Сценарий демонстрации (3 минуты)

1. **Новый выпуск.** Нажать пример «Короткое описание». Показать, что эмитент описал условия одной фразой.
2. **Разобрать описание.** Подсвеченные фрагменты текста, шкала «из описания / уточнено / по умолчанию». Система задаёт пять вопросов, которых нет в описании: минимальный объём, дата размещения, округление, перенос выплат, досрочное погашение.
3. **Ответить на вопросы** кнопками и нажать «Сформировать пакет». Показать шаги сборки: график, документ, контракт, компиляция, EVM, анализ.
4. **Пакет выпуска.**
   - «Решение о выпуске» — документ по шаблону оператора, скачать DOCX.
   - «График выплат» — перенос выплаты с субботы 15.05.2027 на понедельник.
   - «Смарт-контракт» — те же суммы и даты в коде.
5. **Проверки.** 24 проверки, исполнение в EVM: заявки вне периода, неквалифицированный инвестор, выплаты по графику, погашение, возврат денег при несостоявшемся выпуске.
6. **«Что если код поправили вручную?»** Выбрать «Округление вниз». Проверка находит расхождение по каждому держателю. Показать diff в коде.
7. **Карточка инвестора** — те же условия простым языком для розничного канала.
8. **Метрики** — время подготовки, доля параметров из описания, бенчмарк разбора.
9. **Контур и безопасность** — внешних вызовов нет, модель подключается в контуре, соответствие 152-ФЗ, 115-ФЗ, 259-ФЗ.

Подготовка: запустить сервис, один раз прогнать бенчмарк на странице «Метрики».
