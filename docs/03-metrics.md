# Продуктовые метрики

## Главная метрика

**Время от описания условий до пакета выпуска, готового к проверке юристом.** Пакет считается готовым, если в нём нет непройденных проверок.

## Метрики, которые продукт считает уже сейчас

Все значения видны на странице «Метрики» и в выгрузке пакета выпуска.

| Метрика | Как считается | Зачем |
|---|---|---|
| Время подготовки | От начала ввода описания до сформированного пакета | Главная метрика ценности |
| Доля параметров из описания | Поля с происхождением «из описания» / все поля | Насколько меньше ручного ввода |
| Уточняющих вопросов на выпуск | Число вопросов, заданных системой | Нагрузка на пользователя |
| Пройденные проверки | Доля проверок со статусом «пройдена» | Качество пакета |
| Пойманные ошибки | Внесённые в код ошибки, которые обнаружили проверки | Надёжность проверки исполнением |
| Полнота и точность разбора | Бенчмарк на эталонных описаниях с известными параметрами | Качество ИИ-части, контроль при смене модели |

## Текущие результаты

| Замер | Результат |
|---|---|
| Бенчмарк разбора, 20 описаний, правила без модели | Полнота 96,9%, точность 100%, без ошибок 18 из 20 |
| Ошибки в коде: округление вниз, выплата на день раньше, нет минимального объёма | Пойманы 3 из 3 |
| Проверок на выпуск | 24: арифметика, календарь, регуляторика, исполнение в EVM, статический анализ |

Где разбор ошибается: числа словами («триста миллионов») и условные формулировки («если заявок меньше 100 млн — выпуск не состоится»). Для таких случаев подключается языковая модель. Бенчмарк позволяет сравнить её с правилами на одном наборе.

## Метрики пилота

| Метрика | База | Цель |
|---|---|---|
| Время до пакета, готового к проверке | Фиксируем на интервью и первых выпусках | Сокращение в разы |
| Итерации правок решения о выпуске | Текущий процесс оператора | Одна итерация на типовой выпуск |
| Расхождения документа и кода в размещённых выпусках | Инциденты оператора | Ноль |
| Доля параметров из описания на реальных обращениях | Бенчмарк на реальных описаниях | Не ниже 60% |
| Выпусков на сотрудника в месяц | Текущая загрузка команды | Рост без расширения команды |

## Контроль качества ИИ

1. Значение от модели принимается, только если цитата-обоснование действительно есть в тексте.
2. Каждый параметр показывает происхождение: из описания, уточнено, по умолчанию, из реестра.
3. Пользователь подтверждает спецификацию перед генерацией.
4. Бенчмарк запускается при смене модели или промпта.
